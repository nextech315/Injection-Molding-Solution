AI 머신러닝 기반 통합 사출 솔루션 (IM-SOLUTION Suite)

불량 진단, Moldflow 자동 최적화, 대리 모델, 실시간 자율 제어(Edge AI)까지 — 8대 핵심 모듈이 유기적으로 통합된 플랫폼입니다.

The Problem

기존 사출 성형 방식의 한계

현장 경험에만 의존해온 불량 대응 방식은 재현성과 확장성에 분명한 한계가 있습니다.

늦은 대응, 반복되는 손실

불량 발생 후 원인 파악에 수 시간, 조건 재설정에 다시 여러 차례의 시험 생산이 소요됩니다. 생산 중단과 폐기 비용이 반복적으로 발생합니다.

숙련 인력에 대한 높은 의존도

경험 많은 엔지니어가 없으면 최적 조건 도출이 어렵습니다. 노하우가 개인에게 귀속되어 조직 차원의 정량적 이전이 어렵습니다.

범용 대응표의 낮은 적합도

표준 트러블슈팅 표와 문헌 데이터는 제품·금형·소재별 특성을 반영하지 못해, 실제 생산 조건과 괴리가 발생합니다.

NexTech AI 통합 솔루션

실제 공정 데이터와 Moldflow 해석 데이터를 결합한 AI가 수 초 안에 최적 조건을 도출합니다. 현장 전문가 노하우도 정량적으로 자동 반영됩니다.

Integrated Architecture

IM-SOLUTION 8대 모듈 통합 플랫폼

현장 사출 데이터, CAE 해석, AI 대리 모델, 실시간 자율 제어 및 특화 지식을 망라한 8대 핵심 시스템입니다.

MOD-01

사출 불량 종합 솔루션 AI

Total Defect Solution AI

설비, 금형, 원자재, 사출 조건을 총망라한 통합 진단 알고리즘으로 10대 사출 불량을 동시 분석하고 최적 개선 조건을 도출합니다.

● 10대 불량 동시 최적화
MOD-02

Moldflow CAE 연동 최적화

Moldflow OptiSolution AI

Moldflow 해석 수치와 실제 사출 성형 데이터를 결합해 웰드라인, 수축, 미성형 등의 잠재 결함을 사전에 감지하고 최적 공정을 제안합니다.

● CAE-실성형 융합 분석
MOD-03

AI 대리 모델 시뮬레이션

Moldflow Surrogate AI

고차원 유동해석 데이터를 기반으로 AI 대리 모델(Surrogate)을 구축하여 수 시간 걸리는 CAE 시뮬레이션을 수 초 만에 초고속 가상 재현합니다.

● 초고속 대리 모델 시뮬레이션
MOD-04 ★ 핵심

Moldflow 자동 최적화

LHS 30-Case DoE & Auto-Solver

Moldflow 해석 1건을 기준으로 LHS 실험계획 30건을 설계하고, 자동 해석한 결과로 사출 불량 개선 최적화 알고리즘이 최적 공정조건을 도출합니다.

● LHS 30건 실시간 자동 루프
MOD-05

사출 특화 RAG 지식 허브

Injection Domain RAG Hub

심야 자율 크롤러가 글로벌 논문과 매뉴얼을 수집하며, 기계 물리 연산과 결합해 '보압 15MPa 감압' 등 수치형 맞춤 처방전을 제공합니다.

● 심야 크롤러 & 하이브리드 처방
MOD-06

사출 CT 정밀 분석 시스템

Auto-AI Cycle Time Predictor

과거 이력과 공정·해석 조건을 자동 분석하여 앙상블 ML 엔진(NOPRECT)으로 최적 사이클 타임(CT)을 정밀 산출하고 생산성을 극대화합니다.

● 앙상블 NOPRECT CT 산출
MOD-07

공정 작업순서 최적화 엔진

Sequence GA Optimizer

사출 설비 시간과 취출·인서트 등 후공정 작업을 단일 타임테이블로 연동하고, 유전 알고리즘으로 작업자 배치 최적화 및 최대 CAPA를 도출합니다.

● Sequence GA 작업자 밸런싱
MOD-08

사출기 데이터 정제 변환기

Machine Log ETL Converter

● 다기종 사출 로그 고속 ETL
Core Deep-Dive · MOD-04

Moldflow 자동 최적화 파이프라인

Moldflow 해석 1건을 기준으로 LHS 실험계획 30건을 설계하고, 자동 해석한 결과로 사출 불량 개선 최적화 알고리즘이 최적 공정조건을 도출합니다.

01

실행 폴더 / 표준 해석 (Baseline)

Moldflow 시뮬레이션 작업 폴더를 지정하고, 초기 1회차 기준 해석 데이터(Baseline)를 자동으로 인지 및 로드합니다.

02

사출 불량 항목 / 변수 & 타겟 설정

개선할 불량 항목(웰드라인, 수축, 미성형 등)과 조절할 공정 변수(용융온도, 금형온도, 사출속도, 보압) 및 제약 범위를 설정합니다.

03

최적 실험계획법 생성 (LHS 30 Cases)

다변량 파라미터 공간을 빈틈없이 균일하게 탐색하는 라틴 하이퍼큐브 샘플링(LHS) 기법으로 30건의 정밀 실험 조건을 자동 설계합니다.

04

실시간 자동 해석 (Background Loop)

사람의 개입 없이 Moldflow API 및 VBScript와 실시간 연동되어 30건의 DoE 해석을 백그라운드에서 순차적으로 자동 실행하고 결과를 추출합니다.

05

AI 머신러닝 최적화 조건 도출

수집된 30건의 고정밀 데이터를 AI 머신러닝 알고리즘으로 학습해, 불량 위험도를 최소화하는 수렴 완료 최적 공정 조건을 정량 도출합니다.

06

Moldflow 최종 검증 & Closed-Loop

도출된 최적 파라미터를 Moldflow에 재주입하여 검증 해석을 완료하고, 현장 사출기 HMI/PLC에 즉시 반영 가능한 리포트를 생성합니다.

Core Features

현장 엔지니어를 위한 핵심 기능

이론과 현장 경험을 결합한 기능 설계로, 도입 즉시 효과를 체감할 수 있습니다.

AI 알고리즘 자동 선택

데이터 크기와 특성을 분석해 RandomForest, XGBoost, GradientBoosting, Logistic Regression 등 6종 알고리즘 중 최적 모델을 자동 선택합니다. CV R² 기반 교차검증으로 신뢰성을 보장합니다.

역추론 최적화

4가지 수치 최적화 알고리즘이 동시에 실행되어 위험도를 최소화하는 공정 조건을 5초 이내에 도출합니다. 전문가 제약 조건을 반영한 현실적인 값을 제공합니다.

전문가 노하우 통합

특정 공정 변수를 고정하거나 목표값을 지정하는 전문가 제약 조건 기능으로, 숙련 엔지니어의 경험을 AI 진단에 정량적으로 반영합니다.

변수 민감도 분석

공정 변수를 하나씩 변화시킬 때 불량 위험도가 어떻게 달라지는지 시각화합니다. 어떤 변수가 가장 중요한지 즉시 파악할 수 있습니다.

상관관계 히트맵

34개 공정 변수와 10대 불량 간의 상관계수를 컬러 매트릭스로 표시합니다. 개선 우선순위를 한눈에 파악하고 데이터 기반 의사결정을 지원합니다.

AI 전문가 리포트

Groq LLM 기반 AI가 분석 결과를 해석해 현장 작업자가 즉시 실행할 수 있는 조치 사항을 자동으로 작성합니다.

AI Engine

데이터에 맞는 최적 알고리즘을 자동 선택

단일 알고리즘에 의존하지 않습니다. 데이터 크기와 불량 특성에 따라 교차검증을 통해 가장 정확한 모델을 선택합니다.

Tree

RandomForest / ExtraTrees

비선형 중간 규모 데이터에 최적입니다. 과적합에 강하고 안정적인 예측을 제공합니다.

Boost

XGBoost / GradientBoosting

복잡한 패턴과 대규모 데이터에서 강력한 성능을 발휘합니다. 오차를 순차적으로 줄여 높은 정확도를 달성합니다.

Linear

Logistic Regression / Ridge

소규모 선형 데이터에 적합합니다. 빠르고 해석이 쉬워 기준 모델로 활용됩니다.

Autonomous Control · Edge AI

실시간 자율 제어 (Edge AI Daemon)

위험을 진단하는 것을 넘어, 사람이 개입하기 전에 AI가 스스로 공정 조건을 재설정합니다.

1

실시간 센서 스트림 모니터링

사출기 HMI와 연동된 최대사출압·쿠션량·석백·중량 데이터를 실시간으로 수집하며 종합 불량 위험도를 상시 추론합니다.

2

이상 감지 — 위험도 급등

공정 조건이 흔들리면 위험도가 임계치를 넘어 급등합니다. 실제 데모에서는 정상 상태 대비 95.0%까지 치솟는 상황을 재현했습니다.

3

AI 자율 SV 재계산

사람의 개입 없이 AI가 최적 공정 조건(SV)을 역산출해 즉시 피드백합니다. XAI 분석으로 어떤 변수가 위험을 유발했는지도 함께 설명합니다.

4

약 12초 만에 정상화

재계산된 조건이 적용되며 위험도가 다시 임계치 이내로 돌아옵니다. Error SV·Optimized SV 데이터를 그대로 다운로드해 현장 PLC 반영도 가능합니다.

Knowledge RAG · MOD-05

쌓일수록 똑똑해지는 사출 지식 AI (RAG)

범용 LLM은 원론만 답합니다. 수학적 물리 연산, 글로벌 최신 자료, 그리고 우리 공장만의 노하우를 융합해 숫자로 된 처방전을 제시합니다.

잠들지 않는 AI (Nightly RAG Crawler)

매일 자정부터 새벽 5시까지 AI가 스스로 검색어를 기획해 전 세계 사출 논문·포럼·기술 자료를 수집하고 지식 DB에 누적합니다. 출근하면 시스템은 어제보다 더 똑똑해져 있습니다.

하이브리드 처방전 알고리즘

형개력·스크류 직경 등 기계 스펙과 현재 세팅값을 수학적으로 계산해 "보압을 15MPa 낮추십시오"처럼 구체적인 수치로 처방합니다. 두루뭉술한 원론이 아닙니다.

우리 공장 맞춤형 사내 지식 DB

과거 불량 해결 사례와 작업자 피드백을 AI가 학습해 우리 금형에 맞는 조건을 찾습니다. 퇴사자의 노하우도 시스템에 남고, Q&A 챗봇으로 사내 기록을 바로 물어볼 수 있습니다.

실제 화면 & 데모 영상
사출 지식 특화 RAG AI 진단 솔루션

설비 스펙, 다단 제어 사출 조건, 시뮬레이션 데이터, 사내 현장 경험을 교차 검증해 현재 조건과 개선 조건을 파라미터 단위로 비교합니다. 금형 온도 +12℃ 등 변경 항목과 수지 거동학적 개선 요인까지 근거와 함께 설명합니다.

실시간 사출 지식 수집 & RAG 기반 지식 누적형 대시보드
