Core Deep-Dive · MOD-04

Moldflow 자동 최적화 6단계 엔터프라이즈 파이프라인

"Moldflow 해석 1건을 기준으로 LHS 실험계획 30건을 설계하고, 자동 해석한 결과로 사출 불량 개선 최적화 알고리즘이 최적 공정조건을 도출합니다."

01

실행 폴더 / 표준 해석 (Baseline)

Moldflow 시뮬레이션 작업 폴더를 지정하고, 초기 1회차 기준 해석 데이터를 자동으로 인지하여 베이스라인 품질 지표(웰드라인 길이, 사출압, 수축)를 로드합니다.

02

불량 항목 / 변수 & 타겟 설정

개선하고자 하는 중점 불량 항목과 조절할 4대 핵심 공정 변수(용융온도, 금형온도, 사출속도, 보압)의 상한/하한 범위를 엔지니어 제약 조건과 함께 지정합니다.

03

최적 실험계획법 생성 (LHS 30 Cases)

다변량 파라미터 공간을 빈틈없이 균일하게 탐색하는 라틴 하이퍼큐브 샘플링(Latin Hypercube Sampling) 기법으로 30건의 정밀 실험 조건을 1초 만에 자동 생성합니다.

04

실시간 자동 해석 (Background Loop)

Moldflow API 및 자동화 VBScript와 실시간 연동되어 30건의 DoE 해석을 백그라운드에서 순차적으로 자동 실행하고 시뮬레이션 결과 데이터를 무인 추출합니다.

05

AI 머신러닝 최적화 조건 도출

수집된 30건의 고정밀 CAE 결과를 앙상블 머신러닝 알고리즘으로 학습해, 웰드라인과 변형 위험도를 극소화하는 수렴 완료 최적 공정 조건을 정량 도출합니다.

06

Moldflow 최종 검증 & Closed-Loop

도출된 최적 파라미터를 Moldflow에 재주입하여 검증 해석을 완료하고, 현장 사출기 HMI/PLC에 즉시 반영 가능한 표준 성형 조건표(SV)를 자동 출력합니다.

Autonomous Control · Edge AI

2-Tier 아키텍처 & Edge AI 실시간 자율 제어

사출기에 스스로 생각하고 조치하는 '두뇌'를 이식합니다. 위험도가 급등해도 사람이 개입하기 전에 AI가 공정 조건을 스스로 재설정합니다.

1

실시간 센서 스트림 모니터링

사출기 HMI와 연동된 최대사출압·쿠션량·석백·중량 등 31개 이상 채널 데이터를 0.1초 단위로 수집하며 종합 불량 위험도를 상시 추론합니다.

2

이상 감지 — 위험도 급등

원자재 로트 변경이나 금형 온도 드리프트로 위험도가 임계치(30%)를 초과하면 즉시 비상 제어 모드로 전환됩니다. (실제 데모 95.0% 급등 재현)

3

AI 자율 SV 재계산 & XAI

사람의 개입 없이 AI가 최적 공정 조건(Optimized SV)을 역산출하여 기계로 피드백하고, XAI(설명 가능한 AI) 기여도 분석으로 원인 인자를 명확히 제시합니다.

4

약 12초 만에 24.9%로 자율 정상화

재계산된 조건이 사출기 PLC에 자동 적용되어 위험도가 24.9%로 안정화됩니다. 연속 불량을 원천 차단하는 완전한 Closed-Loop 자율 제어를 실현합니다.
